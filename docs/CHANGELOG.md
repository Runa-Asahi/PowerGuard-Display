### 未发布（分支 feat/v1.1-hardening-shutdown-restore）

### 自迭代第 4 轮
- **停电期间开机保护**：启动时为电池供电、没有恢复标记，但内屏未点亮（Windows 按记忆只点亮了没电的外接显示器）→ 直接进入断电保护流程，避免开机即黑屏。关闭“断电自动切屏”时不生效。
- **DDC/CI 校验补全**：Windows 自己已经切回外接独占时（不需要再切换），自动恢复同样会做 DDC/CI 校验；正常使用中连续 5 次学习失败后本次运行停止探测。
- **睡眠/休眠恢复后盖子状态重置为未知**，防止丢失开盖通知导致内屏守护一直不工作。
- 托盘状态项改用统一状态用语；托盘“尝试恢复外接显示器”更名为“尝试恢复首选显示模式”，与控制台一致；设置项与日志筛选控件补充读屏名称。
- **控制台新增自启动提醒**：未开启 / 任务被禁用 / 指向其他位置时，在状态横幅下方给出提示。

### 新增（自迭代第 3 轮）
- **盖子感知**：注册 GUID_LIDSWITCH_STATE_CHANGE。断电且合盖时内屏守护暂停重试并提示，开盖立即切回内屏（不受限速影响）。
- **崩溃看门狗**（默认开启）：进程因未处理异常终止时自动重启，每小时最多 3 次；新实例等待旧互斥体（含被遗弃）后接管。
- **实验：DDC/CI 恢复校验**（默认关闭）：正常使用时先确认外接显示器支持 DDC/CI；自动恢复后连续 3 次（间隔 2 秒）读 VCP 0xD6 均无应答才判定显示器没电，切回内屏继续等待。每个流程最多回退一次；手动恢复永不被否决；“无法判断”一律按原有行为。
- 托盘与控制台使用统一状态用语（StatusText）。设置文件升级到 v3（自动迁移）。

### 评估后未采用
- WMI WmiMonitorConnectionParams / BasicDisplayParams：与 Windows 拓扑同源，EDID 残留时同样过时。
- PnP / WM_DEVICECHANGE 显示器事件：EDID 残留时不产生移除事件。
- “电池专用显示拓扑”：Windows 没有此概念，内屏守护已达到同样效果。
- SDC_SAVE_TO_DATABASE 搭配拓扑标志：官方文档明确无效。
- GUID_CONSOLE_DISPLAY_STATE：只反映系统是否关闭显示输出，无助于判断外接显示器是否有电。
- **修复断电后内屏黑屏**（实机 2026-10-26）：断电瞬间外接显示器短暂消失，程序读到“已是内屏”便跳过切换；约 2 秒后显示器又被 Windows 识别，Windows 自动切回“仅第二屏幕”，程序没有再处理。现在断电时总是下发切内屏命令，并在断电期间持续守护内屏（有限速）。
- 切屏默认先用 v1.0.0 实机验证过的 DisplaySwitch.exe，第二次尝试改用 SetDisplayConfig；空闲轮询恢复为 3 秒；电源变化立即记录不等锁。
- 关机前恢复：来电后外接显示器尚未稳定可用时不切外接。
- 体验：切回内屏不再弹确认框；电池供电时手动恢复外接会额外警告；无法切回内屏或内屏反复被切走时发出提示音和通知（无视通知开关）；断电期间的控制台横幅和托盘提示显示“正在使用笔记本内屏”和已纠正次数。

### v1.2.0
> 2026-10-26 重新发布：修复“升级后仍运行旧实例”的问题。新 exe 检测到另一个版本或另一位置的实例在运行时，会询问并替换它（先请求正常退出，旧版本不支持时再结束进程）。界面和托盘显示的版本号改为带构建提交（例如 `v1.2.0 (abc1234)`）。CI 在打 tag 时按 tag 设置版本并校验产物版本。

> 说明：之前发布的 v1.1.0（多信号保护）因设计问题已撤回，v1.2.0 以已在实机验证过的 1.0.0 为基线，**不包含**多信号 / 外接路径消失触发，断电判定仍然只看“市电 → 电池”。

- **新功能：关机 / 重启 / 注销前尽力切回首选显示模式**（见 [设计文档](DESIGN.md#关机前恢复首选显示模式v12-新增默认开启)），默认开启，可在设置中关闭。
- 切屏默认改用原生 `SetDisplayConfig`，不再依赖 DisplaySwitch.exe 的参数格式（保留为回退）；DisplaySwitch 超时后会关掉残留的“投影”菜单。
- 稳定性：配置 / 恢复标记文件被占用或无权限时不会再导致启动崩溃（不覆盖、不改名，按保守策略处理）；启动流程有全局异常兜底；协调器状态改为线程安全的快照，修复取消和释放之间的竞争。
- 性能：显示接口类型缓存、轮询改为正常 10 秒 / 恢复中 2 秒且不叠加；日志改为常驻写入、跨天自动清理；日志页不再每条整体重排，搜索带防抖。
- 体验：自定义托盘图标、“暂停 1 小时”、托盘切屏时菜单置灰；电源 UPS（PoAc=2）通知不再导致状态来回跳。
- 工程：GitHub Actions（windows-latest）构建、测试并发布自包含和依赖框架两种包；拓扑推导移到 Core 并补齐测试（57 → 96 个）；配置结构版本 v2，自动迁移；修正 README 中的 `.slnx` 文件名。

### v1.1.0（已撤回）
多信号保护（外接路径消失触发等）。实机测试发现显示路径状态与显示器实际物理状态可能不一致，保护判断不可靠，已停止发布。

### v1.0.0
第一版：市电转电池时自动切回笔记本内屏；来电后外接显示器稳定可用时恢复首选模式；重启后继续未完成的恢复；登录自启动。
